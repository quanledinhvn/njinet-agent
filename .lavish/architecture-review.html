Kết luận

Không có domain core độc lập để Clean Architecture bảo vệ.

Đây là service orchestration: giá trị nằm ở LangGraph, MCP, queue và callback. Bọc mỗi thứ vào port/interface lúc này tạo thêm file và injection mà không giảm coupling thực tế.

Việc nên làm trước

  1. Chọn code là source of truth, cập nhật hoặc archive các docs/spec cũ về Redis Pub/Sub, streaming và checkpointer.
  2. Quyết định rõ checkpoint có còn trong scope. Nếu không: xóa `runtime/checkpointer.py`, dependency Postgres checkpoint và biến môi trường DB; nếu có: wiring lại vào `run_agent` với `thread_id`.
  3. Sửa hygiene: test config bị ảnh hưởng bởi `.env` cục bộ; `ruff check` có một import chưa sort.

Ngưỡng để tách use case

  • Thêm mode chạy khác (sync / scheduled / human approval) nhưng cùng rule nghiệp vụ.
  • Nhiều LLM, MCP backend hoặc callback transport cần switch theo tenant/runtime.
  • Policy nghiệp vụ độc lập xuất hiện: quota, audit, retry/idempotency, authorization orchestration.

Khi đó, chỉ tách `application/run_agent.py` và các protocol cần thiết — không cần dựng full Clean Architecture trước.

Clean Architecture mỏng nếu cần áp dụng

src/njinet_agent/
├── domain/                         # Chỉ rule/value object thật sự độc lập (có thể chưa cần)
│   └── errors.py
├── application/
│   ├── ports.py                    # Protocol: ToolLoader, ReplySender, AgentRunner
│   └── run_agent.py                # use case: RunAgent.execute(command)
├── adapters/
│   ├── inbound/http.py             # FastAPI router + Pydantic request/response
│   ├── inbound/worker.py           # ARQ job → RunAgent
│   ├── outbound/langgraph.py       # build graph + invoke
│   ├── outbound/mcp.py             # MultiServerMCPClient
│   └── outbound/backend.py         # httpx callback
├── infrastructure/
│   ├── config.py                   # Settings, wiring/composition root
│   └── worker.py                   # WorkerSettings
└── main.py                         # app lifespan + dependency wiring

`domain/` rỗng là chấp nhận được; đừng tạo entity/repository giả. `application/ports.py` chỉ có các port cần thay thế hoặc cần fake trong test.
